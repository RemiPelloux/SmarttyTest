Version 1.2.0

SmartTest documentation

SmartTest reads a change, follows it through your code to the tests that can detect a regression, and runs only those, through Jest, Vitest, node --test, Playwright, Cypress, Angular, pytest, unittest, PHPUnit or Pest. When it cannot rule a test out, it runs it.

  1. 1Install and looksmarttest initInstall @tkmremi/smarttest as a dev dependency; init detects the runners and explains the config before writing it.
  2. 2Gate commits and pushessmarttest hook installRuns the affected tests on exactly what is committed or pushed.
  3. 3Run it in CIsmarttest ciFinds the base, deepens shallow clones, and keeps the full suite where you want it.

New in 1.2

  • smarttest audit measures missed tests on your project instead of assuming none.
  • Angular workspaces, and a Python preview for pytest and unittest.
  • Lockfile changes select by package, and a rollout guide from six real repositories.
