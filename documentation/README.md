## Conventions

- **§ references** (for example §11.4) point to sections of the [PRD](product/PRD.md). Letter codes (for example G05) point to its engineering backlog (§34).
- **ST-### IDs** are v1.0.0 user stories. They are defined in [`backlog.data.mjs`](planning/release-1.0.0/backlog.data.mjs) and rendered into [epics](planning/release-1.0.0/epics/README.md).
- Pages say which version implements them. Behaviour is backed by the unit and integration suites (`pnpm test`).
- Animated illustrations in [`assets/`](assets) are generated by `pnpm assets:build`. Don't edit them by hand.
