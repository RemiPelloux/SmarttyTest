# Documentation

SmartTest reads a change, follows it through your code to the tests that can detect a regression, and runs only those, through Jest, Vitest, `node --test`, Playwright, Cypress, Angular, pytest, unittest, PHPUnit or Pest. When it cannot rule a test out, it runs it.

Start in three steps: [install and run `smarttest init`](guides/getting-started.md), [gate commits and pushes](guides/commit-hooks.md), [run it in CI](guides/ci.md).

New in 1.1: [`smarttest audit`](guides/audit.md) measures missed tests on your project, [Angular](guides/angular.md) workspaces, a [Python preview](guides/python.md), lockfile changes selected by package, and a [rollout guide](guides/rollout.md). See the [changelog](../CHANGELOG.md).

New in 1.2: a [PHP preview](guides/php.md) with Laravel routes, [CI annotations](guides/ci.md#annotations-on-the-pull-request) on pull requests, live Playwright specs left to `--live`, an opt-in [commit trailer](guides/commit-hooks.md#commit-trailer), `smarttest sync` upgrade proposals, and barrel pruning.
